# Seaninho no celular

Página de uso pessoal (app da Tela de Início do iPhone) com as sessões do Claude Code e as atualizações do Seaninho Pro
dos meus PCs. Não tem dados aqui: tudo vem de um Supabase pessoal, e só aparelhos pareados (com chave própria)
conseguem ler ou pedir algo. A chave publicável em `config.js` é pública por natureza.
